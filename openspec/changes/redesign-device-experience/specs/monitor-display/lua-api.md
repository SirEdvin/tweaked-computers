# monitor-display API compatibility

No new public Lua API is introduced by this redesign. The complete existing signature/type/error/event contract remains in [the baseline API](../../../add-native-circuit-computers/specs/monitor-display/lua-api.md).

[Shared compatibility and exact editor action mapping](../../api/compatibility.md) specifies the preserved version-1 behavior, identity and persistence boundaries and concrete user workflows. The accompanying `spec.md` changes presentation/interaction only; it does not remove baseline APIs.
