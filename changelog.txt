Version: 0.1.8
Date: 2026-10-18
  Features:
    - Add a live single-line Console with native typing, paste, caret editing and Enter or Execute submission beside the saved program.
    - Retain shared save-backed scalar/table graphs, aliases, cycles and checked peripheral bindings across commands, close/reopen and save/load.
    - Add explicit confirmed Reset Shell without resetting saved source, application state or the running program. No command history is provided.
  Changes:
    - Share existing computer scheduling and work budgets between program and shell; recheck live peripheral authority on every call.
    - Keep earlier factory effects on command failure while retaining the previously committed scratch graph. User functions cannot be retained.
    - Run/Apply and explicit Stop reset shell values; power loss retains values but cancels pending commands and shell-owned outputs.
  Bugfixes:
    - Preserve shell syntax explanations and EOF positions, settle Console Follow after native layout, and show stale-reset errors in the active Console.
  Info:
    - ALPHA: back up saves. Factorio 2.0.77 base and optional Space Age; no OS, filesystem, unrestricted Lua or command history.
    - Native Console workflows tested in both modes; real two-client late join and cold server resume tested in base only.
    - Software-rendered client acceptance is not a GPU FPS, real-time latency or busy-factory performance guarantee.
    - Retains 0.1.7 Foundry art, connected-subpixel charts, component reuse and live Map budgets; this release does not increase production safety ceilings.

Version: 0.1.6
Date: 2026-10-16
  Features:
    - Add live Map settings for compilation, execution, allocation and shared host-work budgets.
    - Increase their defaults fivefold while preserving already-spent tick credits.
    - Include a whole-curve sine chart that updates every selected monitor together every two ticks.
  Optimizations:
    - Prepare and retire damaged cells while transferring unchanged native monitor objects.
    - Cache bounded private exact-source compilation proofs with identical cold/warm admission charges.
    - Reuse physical proofs only within a non-yielding callback and reviewed monitor methods.
  Bugfixes:
    - Avoid permanently deferring small callbacks when configured per-computer budgets exceed the shared allowance.
    - Invalidate sparse monitor presentation when settings paste replaces a palette.
  Info:
    - ALPHA: back up saves. Graphical-client and multiplayer validation remains user-owned.
    - Two-tick publication is 30 updates/second only at 60 UPS, not a universal client-FPS guarantee.
    - Four full 6 by 6 walls remain CPU-heavy; dense grids and busy factories can reduce real-time smoothness.
    - Renderer maintenance, preparation-cell, object and commit caps are unchanged.

  Info:
