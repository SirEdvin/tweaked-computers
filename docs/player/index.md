# Tweaked Computers — ALPHA, in development

Native circuit computers for Factorio 2.0.77, with base alone or optional Space Age.

This site is an infrastructure scaffold, not the complete player guide. The public
main branch currently contains the compiler/sandbox foundation, not playable
computer entities or a complete gameplay API. Do not install it expecting a finished mod.

The planned mod includes an in-game program editor, same-color peripheral discovery,
logic handlers, persistent string/hash databases, merging monitors and typed device
configuration. Planned features are not claims about this bootstrap build.

Graphical editing, focus, touch, rendering, rotations and multiplayer joining have
not been client-verified by agents. The user will test the client after the full
implementation. Back up saves before trying any future alpha.

- [Source and implementation status](https://github.com/SirEdvin/tweaked-computers)
- [Report a problem](https://github.com/SirEdvin/tweaked-computers/issues)

The full player guide and API reference will replace this scaffold before the
public Factorio alpha release. There is no Mod Portal release from this checkpoint.
