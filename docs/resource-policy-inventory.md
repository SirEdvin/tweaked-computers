## Shared constant coverage

All names in `scripts/runtime/limits.lua` are assigned here; duplicates across rows are deliberate because removing a declaration without changing its import/validator/advertisement is incomplete.

- Format/version metadata, not resource settings: `api_version`, `compiler_version`, `storage_version`.
- Work/cache policy: `callback_work`, `callback_allocations`, `compile_work`, `host_work_per_tick`, `maintenance_work_per_tick`, `compiler_cache_bytes`.
- Compiler/host recursion and source shape: `host_stack_depth`, `identifier_bytes`, `tuple_entries`, `callback_depth`. The obsolete `source_bytes`, `generated_source_bytes`, `source_nodes`, `source_tokens`, `source_nesting` and `handler_names` fields are removed. Saved/active source now uses distinct owners on the existing host account; Console and other downstream storage guards remain pending.
- Global metadata counts: `active_computers`, `active_logic_handlers`, `aggregate_subscriptions`, `aggregate_owned_outputs`, `registry_entries`, `owned_children`, `shell_sessions`, `host_hooks`.
- State/Data shape: `state_bytes`, `state_entries`, `data_depth`, `string_bytes`, `table_entries`, `peripheral_call_bytes`, `peripheral_call_entries`. The former `data_nodes` declaration and its shared-copy/event/timer checks are removed; node statistics remain for accounting. Durable service copies use retained-memory admission instead of `peripheral_call_bytes`, but non-durable copies and other shape checks still require integration.
- Queues/registrations: `event_queue_bytes`, `timers`, `subscriptions`, `shell_pending_entries`, `shell_pending_bytes`. The independent `event_queue_entries` declaration/setting/enforcement is removed; the existing serialized byte charges are unchanged, so accepted entries need no re-encoding or eviction.
- Shell/retention: `console_entries`, `console_bytes`, `shell_source_bytes`, `shell_bindings`, `shell_value_bytes`, `shell_nodes`.
- Discovery/presentation: `network_nodes`, `network_edges`, `sync_group_refs`, `sync_group_members`, `sync_group_cells`, `sync_groups_per_run`.
- Advertised latency, not blanket native guarantees: `topology_latency_ticks`, `fail_safe_latency_ticks`.

## Boundaries that remain non-configurable

Keep exact safe-integer IDs/revisions/ticks and native signed/unsigned numeric domains; dense sequence shape; closed field sets; source/global trust restrictions; version/ABI identity; foreign-value rejection; color/volume/prototype validity; role/wire/force/surface/player authority; conflict/ownership exclusion; and exactly-once commit/result markers. Fixed cardinality of a closed record's allowed fields is structural validation, unlike limiting how many records can exist. Deterministic payload/metadata accounting weights and estimated work costs are not separate resource ceilings, but their coverage still needs verification.

Task 11.1 must revisit all these source paths, regenerated files, tests and advertisements after implementation and establish that no removed guard survives indirectly. This inventory does not justify raising budgets, relabeling a fixed capacity as a native constraint, dropping data, narrowing grammar, or declaring a service verified from a helper test.
