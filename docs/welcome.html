Program your factory.

Tweaked Computers adds programmable Lua controllers to Factorio. Use them to read circuit signals, control machines, share data, and make interactive displays.

Each computer runs one source document with named callbacks. The API gives access to computers and peripherals. It does not give access to an operating system, a filesystem, or native Factorio objects.

This mod supports Factorio 2.1. Space Age is optional.

Set up a computer

  1. Install the mod. First, make a backup of your save and its matching mods. Enable Tweaked Computers in Factorio’s Mods screen. Restart Factorio when it asks you to do so. This is an alpha release. Use a copy of your save for tests.
  2. Research and craft. Research Native circuit computers. Craft a computer. Place the computer. It does not need electricity. This first example does not need other devices or wires.
  3. Open the workspace. Clear your cursor. Close any open GUI. Ctrl + left-click the computer. You can still use ordinary clicks for wiring.

Alpha warning: make a save backup before installation, upgrades, or recovery. A mined computer item contains only the hardware. Ordinary pickup and replacement do not keep its contents. Make a save backup before you move a computer. Read the complete compatibility and verification limits.

Your first program

The built-in Starter example keeps a sample counter in saved computer state. It schedules a callback every 60 simulation ticks. It does not control factory machines.

In an empty Editor, choose Starter example. Or paste this complete document:

local function increment(value)
  return value + 1
end

function start(event)
  local total = sample()
  print("Initial sample count:", total)
  computer.every(60, "sample")
end

function sample(event)
  local total = increment(computer.getState("samples") or 0)
  computer.setState("samples", total)
  return total
end
  1. Validate the draft. Validation checks the draft. It does not save or run the program.
  2. Select Save. Save stores the source. It does not replace the active program.
  3. Select Run / Apply. This control activates the saved program.
  4. Open Console. Look for Initial sample count: with a number after it. The timer increases the saved counter. It does not print another line.
  5. Inspect the counter. Enter computer.getState("samples") in Console. Repeat the command later to see the increase. Console calls operate on the real computer. They are not isolated tests.

Save is not Run. Stop is not Reset State. Stop cancels this program’s timer but keeps the counter. A subsequent start uses the saved state. If you close the workspace without Stop, the program continues to run.

Connect the next piece

Connect the peripheral’s Network port to the computer’s Network port with a red or green wire. The Peripherals tab shows the exact names available on that color.
